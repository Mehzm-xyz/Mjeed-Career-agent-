# مسار — مساعد التوظيف الشخصي

مشروع مستقل بواجهة عربية، وخادم Node.js وقاعدة SQLite. لم تُحدد الاستضافة أو شركة الذكاء الاصطناعي. لا توجد أوامر نشر تلقائي أو خدمة مدفوعة تُفعّل عند التشغيل.

## التشغيل

يلزم Node.js 22.13 أو أحدث:

```bash
npm ci
export APP_TOKEN="ضع-هنا-رمز-إدارة-عشوائي-طويل-خاص-بك"
npm start
```

يجب أن يكون `APP_TOKEN` من 24 حرفًا على الأقل. افتح `http://127.0.0.1:3000` وأدخل الرمز. لا تضعه في المستودع. يمكنك ضبط `PORT` و`HOST` و`DATABASE_PATH` من بيئة التشغيل؛ الافتراضي يستمع محليًا ويحفظ القاعدة داخل `data/masar.sqlite`. الترحيلات تُطبق تلقائيًا، ويتوفر أيضًا `npm run db:migrate`.

للنقل إلى أي استضافة تدعم Node.js، احتفظ ببيئة التشغيل والقاعدة على تخزين دائم. لم تُربط استضافة بعينها، ولا تكفي زيارة واجهة المعاينة لتشغيل الخادم.

## الوظائف الأساسية

- ملف مهني، استيراد PDF وDOCX وTXT، وستة حقول للمناصب المستهدفة.
- قائمة استبعاد لجهات العمل الحالية والسابقة تُراجع قبل تجهيز التقديم.
- اكتشاف وظائف منشورة عبر لوحات Greenhouse وLever وAshby، مع إزالة التكرار وترتيب الملاءمة للسيرة والمناصب.
- سجل مستقل للفرص والمسودات والتقديمات المؤكدة؛ تجهيز مسودة لا يثبت إرسالها.
- معاينة بريد محدد بالمسمى والجهة، وإرفاق أصل السيرة PDF عند توفره، وحفظ مسودة Gmail بعد ربط الحساب. لا يوجد إرسال تلقائي.
- متابعة المحادثات المضافة، وحفظ الردود وفصل التصنيف الأولي للرد البشري عن التأكيد الآلي وتعذر التسليم. يتوقف مسار المتابعات عند رد بشري.
- تقرير مهني يميز الحقائق عن التحليل، ويعرض التجاوب والعينة التي مضى عليها أسبوع وترتيب الفرص. العينات الصغيرة لا تنتج تشخيصًا مؤكدًا.
- أدلة سوق بمصدر وتاريخ وحالة تحقق، وتصدير بيانات خاص يتطلب رمز الإدارة.

## ربط Gmail

يتوفر موصل اختياري في `connectors/google-apps-script/Code.gs`. يحتاج تثبيته في حساب Google والموافقة على صلاحياته من صاحب الحساب، ثم ضبط `GMAIL_SCRIPT_URL` و`GMAIL_HMAC_KEY` على الخادم ومفتاح مطابق في إعدادات الموصل. لا تضع أيًا منها في الواجهة أو الكود العام. اتصال Gmail داخل ChatGPT لا ينتقل تلقائيًا إلى هذا المشروع.

إعداد الموصل مرة واحدة:

1. افتح مشروعًا في Google Apps Script بحساب بريد التقديم، والصق `Code.gs`.
2. من إعدادات المشروع أضف `MASAR_SHARED_KEY` بقيمة عشوائية من 32 حرفًا على الأقل، و`MASAR_DRAFTS_ENABLED=true` فقط إن أردت السماح بحفظ المسودات. القراءة تعمل بدون تفعيل المسودات، ولا توجد دالة إرسال.
3. انشره كتطبيق ويب ينفذ بحسابك مع وصول `Anyone` لطلبات الخادم، ووافق بنفسك على صلاحيات Gmail. الطلبات محمية بتوقيع وتوقيت ومعرّف يمنع إعادة الطلب.
4. ضع رابط `/exec` في `GMAIL_SCRIPT_URL` والمفتاح المطابق في `GMAIL_HMAC_KEY` ضمن بيئة الخادم، ثم أعد تشغيله. يوضح «حالة البريد» هل الحساب يطابق بريد ملفك.

بعد الربط، أضف محادثة أرسلت بالفعل من قسم «البريد والردود»: معرّف المحادثة والمستلم والمسمى والجهة وتاريخ الإرسال. يتحقق الخادم من الحساب ومن وجود الرسالة الأصلية قبل متابعتها. لا يقرأ البريد غير المرتبط بمحادثاتك المتابعة.

يفحص الخادم الردود مرة كل 24 ساعة أثناء بقائه يعمل، حتى بعد انتهاء الإرسال، مع زر للفحص الفوري وسجل لنتيجته. عند توقف الجهاز أو الخادم لا يعمل المؤقت؛ يمكن لاحقًا ربط مجدول الاستضافة المختارة بالفحص نفسه. لا يلزم إبقاء صفحة المتصفح مفتوحة.

خطة المتابعة في الأيام 3 و5 و7 تُعرض للمراجعة فقط، والأخيرة انسحاب مهذب عند استمرار غياب الرد. الرد البشري أو فشل التسليم يوقفها. تصنيف الرسائل أولي، والردود الواردة بيانات غير موثوقة وليست تعليمات للنظام.

## الذكاء المهني دون اختيار مزوّد

الترتيب والإحصاءات وأدلة السوق تعمل بقواعد مفهومة على البيانات المحفوظة، ولا تُعرض كتوقعات مؤكدة عن السوق كله. لا يُفترض أن جهة تحتاج موظفًا بسبب خبر غير متحقق، ولا أن غياب الرد يثبت ضعف السيرة.

للتوليد لاحقًا، يستقبل `startServer` محولًا اختياريًا `AI` بواجهة `generate({messages,max_tokens,temperature})` يعيد النص أو صيغة استجابة يدعمها المشروع. لا توجد شركة أو نموذج افتراضيان. دون هذا المحول تظل أوامر التوليد غير مفعّلة، وتبقى كتابة مسودة يدويًا ممكنة.
