# مسار — مساعد التوظيف الشخصي لمجيد

واجهة عربية للجوال وCloudflare Worker مع قاعدة D1. محفوظ هنا مشروع التشغيل الكامل، وليس الصفحة المهنية على Lovable.

## ما يعمل في الكود

- إدارة الفرص والطلبات، تحليل الملاءمة وتوليد مسودات باستخدام Workers AI.
- جلب وظائف السعودية مع تقديم الرياض في الترتيب من Greenhouse وLever وAshby. أُضيفت أربع لوحات جهات فعلية افتراضيًا: Tamara وBRKZ وMinIO وBioCatch.
- ملف مهني أولي من PDF السيرة الفعلي في صفحة المالك. الترحيل لا يستبدل ملفًا سبق تعديله ولا يفرض المناصب المستهدفة.
- استيراد TXT وPDF وDOCX، وتنزيل PDF الأصلي من مسار يتطلب رمز الإدارة ويطابق بصمة الملف.
- حفظ مجمّع للوظائف لتجنب استنزاف حد طلبات D1 في الخطة المجانية.
- تسجيل تأكيدات التقديم اليدوي، مع حد 10 يوميًا خاص بـLinkedIn.

## النواقص الفعلية

التقديم الآلي على LinkedIn ومواقع الشركات، وإرسال البريد والردود والمتابعة، غير موصلة حتى الآن. وجود سجل المحركات أو كود Apps Script لا يعني أنها تكاملات تشغيلية.

النظام منشور على https://saudi-job-copilot.masar-mjedov1957.workers.dev/ مع D1 ورمز إدارة سري. البحث المجدول مفعّل الساعة 09:00 و12:00 و15:00 بتوقيت الرياض. اختبار المتصفح وR2 معطلان. ربط GitHub التلقائي ينتظر تفويض Cloudflare GitHub App لحساب المؤسسة.

## التحقق

```sh
npm ci
npm test
python3 scripts/test_sql_atomic.py
npm run test:runtime
npm run preflight
```

اختبار الواجهة يشغّل JavaScript الفعلي داخل DOM ويفحص التنقل وتسجيل الخروج. اختبار DOCX يستخدم ملفًا حقيقيًا. اختبار runtime يشغّل workerd وD1 محليين؛ يحتاج بيئة تسمح لـWrangler بفحص واجهات الشبكة، ويتنفذ أيضًا في GitHub Actions.

النشر اليدوي: [التعليمات](GITHUB_CLOUDFLARE_MANUAL_AR.md). فحص اتصال منفصل للقراءة فقط يبيّن نقص الأسرار دون طباعة قيمها أو نشر أي مورد.

مصدر السيرة: https://alamri-bd.lovable.app/ — استُخرج PDF في 6 نوفمبر 2026؛ هذا نقل لنص المالك وليس تحققًا مستقلًا من خبراته.

## البحث حسب السيرة

`npm run jobs:search -- --out search-results` يجلب إعلانات فعلية ويرتبها حسب نص PDF المالك، ويصدر CSV وJSON. يمكن اختيار سيرة أحدث: `--cv /path/to/resume.pdf` أو مسميات اختيارية: `--roles "Business Development Manager,Account Executive"`.

الترتيب يعتمد إشارات واضحة من السيرة، ويعرض المتطلبات التي تحتاج مراجعة؛ ليس احتمال قبول أو إثبات ملاءمة. تعطل مصدر لا يخفي خطأه. الواجهة تعرض نفس ترتيب الفرص وفق ملف D1 الحالي. بيانات التواصل المحدثة في الملف تتقدم على بيانات السيرة القديمة عند تجهيز المسودات. البريد داخل الملف ليس جلسة Gmail؛ إرسال البريد يحتاج ربط الحساب وموافقته مستقلاً.

ست خانات للمناصب يختارها المالك. تجهيز الطلب والطابور محميان من الخادم: لا تجهيز دون اختيار ولا لوظيفة خارج المسميات المختارة. البحث وحده لا يرسل طلبات.

لغة التقديم: الجهات الحكومية بالعربية، والبقية باللغة الأساسية لإعلانها، بأسلوب مهني مختصر وطبيعي. سجل إشارات السوق يذكر الإعلان ورابط دليله؛ لا يستنتج خروج موظفين من وجود شاغر. وقت التقديم المسموح 09:00 إلى قبل 17:00 الرياض؛ البحث الدوري مستقل عن إرسال الطلبات.

الأسرار خارج الواجهة: config/secrets.example.json أسماء خانات فارغة فقط. سكربت npm run secrets:configure -- /private/path/secrets.json يرسل القيم من ملف خارج المستودع إلى Cloudflare Secrets. Gmail يستخدم تفويض OAuth أو جسر Apps Script؛ كلمة مرور البريد ليست من أسرار التطبيق المطلوبة. وجود أسماء الخانات لا يعني أن الربط قد اكتمل.
