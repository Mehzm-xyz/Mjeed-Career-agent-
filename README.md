# مسار — مساعد التوظيف الشخصي لمجيد

واجهة عربية للجوال وCloudflare Worker مع قاعدة D1. محفوظ هنا مشروع التشغيل الكامل، وليس الصفحة المهنية على Lovable.

## ما يعمل في الكود

- إدارة الفرص والطلبات، تحليل الملاءمة وتوليد مسودات باستخدام Workers AI.
- جلب وظائف السعودية مع تقديم الرياض في الترتيب من Greenhouse وLever وAshby. أُضيفت أربع لوحات جهات فعلية افتراضيًا: Tamara وBRKZ وMinIO وBioCatch.
- ملف مهني أولي من PDF السيرة الفعلي في صفحة المالك. الترحيل لا يستبدل ملفًا سبق تعديله ولا يفرض المناصب المستهدفة.
- استيراد TXT وPDF وDOCX، وتنزيل PDF الأصلي من مسار يتطلب رمز الإدارة ويطابق بصمة الملف.
- حفظ مجمّع للوظائف لتجنب استنزاف حد طلبات D1 في الخطة المجانية.
- تسجيل تأكيدات التقديم اليدوي، مع حد 10 يوميًا خاص بـLinkedIn.

## النواقص الفعلية

التقديم الآلي على LinkedIn ومواقع الشركات، وإرسال البريد والردود والمتابعة، غير موصلة حتى الآن. وجود سجل المحركات أو كود Apps Script لا يعني أنها تكاملات تشغيلية.

لا يوجد إثبات نشر حي على Cloudflare. يلزم اتصال حساب المالك وقاعدة D1 ورمز الإدارة. البحث المجدول واختبار المتصفح وتخزين أصل السيرة في R2 معطلة افتراضيًا.

## التحقق

```sh
npm ci
npm test
python3 scripts/test_sql_atomic.py
npm run test:runtime
npm run preflight
```

اختبار الواجهة يشغّل JavaScript الفعلي داخل DOM ويفحص التنقل وتسجيل الخروج. اختبار DOCX يستخدم ملفًا حقيقيًا. اختبار runtime يشغّل workerd وD1 محليين؛ يحتاج بيئة تسمح لـWrangler بفحص واجهات الشبكة، ويتنفذ أيضًا في GitHub Actions.
