# مسار — مساعد التوظيف الشخصي (MVP 0.1)

مشروع عربي بواجهة متجاوبة وخادم Cloudflare Worker وD1 وWorkers AI ومتصفح Cloudflare Browser Run.

## ما هو جاهز في الكود الآن؟

- واجهة عربية تعمل كموقع متجاوب على الآيفون والأندرويد والكمبيوتر.
- إضافة وظائف يدويًا مع كشف التكرار، وروابط الجهة ونوع قناة التقديم.
- ملف مهني نصي يحافظ على السيرة الأصلية، ومسميات وظيفية يحددها صاحب السيرة لا النظام.
- تحليل أولي للملاءمة وتوليد **مسودة** سيره موجَّهة باستخدام Workers AI **عند تفعيل خدمات Cloudflare**؛ لا يرسل النموذج طلبات.
- حفظ مسودات التقديم في D1 وإدارة الحالات وسجلها.
- وضع حد داخلي 5 طلبات AI يوميًا وحد 10 طلبات مؤكدة على LinkedIn وحدها في يوم السعودية، دون سقف عددي موحد لبقية المنصات.
- دالة تحقق من وقت السعودية: 09:00 إلى 16:59 (قابلة للتعديل). لا توجد عملية إرسال تلقائي حقيقية في هذا الإصدار.
- اختبار Cloudflare Browser Run على **نموذج اختبار داخلي فقط** `try-form.html`، بعد النشر والتفعيل الصريح. لا يزور مواقع توظيف.
- حماية API برمز `APP_TOKEN` محفوظ كـ Worker Secret (لا تضعه في الكود).
- صفحة استعراض مستقلة `masar-preview.html` بدون حساب ولا اتصالات خارجية.

## غير جاهز — لا تعتبره منتجًا مكتملًا

1. لم يُنشر المشروع على حساب Cloudflare، ولم يُختبر Browser Run فعليًا على Cloudflare.
2. لا يوجد إرسال طلبات توظيف حقيقية ولا ربط Gmail/Apps Script بعد.
3. لا توجد بعد مصادر بحث أو جمع وظائف آلية؛ انتظر السيرة والمناصب المستهدفة لتحديد المصادر.
4. رفع واستخراج PDF/DOCX لم يُنفذ؛ إدخال السيرة حاليًا من نص ملصوق فقط.
5. النص المخصص من AI يحتاج مراجعة بشرية قبل إرساله؛ لا تتبع آليًا للحقائق الدقيقة بعد.
6. رمز APP_TOKEN مناسب لمشروع تجريبي شخصي؛ قبل استعمال بيانات حقيقية يوصى بربط Cloudflare Access وإضافة تحصين ضد إساءة استخدام API.
7. الواجهة متجاوبة وفق CSS، لكن التحقق البصري عبر متصفح محلي لم يكتمل بسبب قيود بيئة الاختبار. اختبارات JavaScript المنطقية نجحت.

## لماذا تطبيق واحد في Cloudflare؟

Cloudflare Workers يدعم تقديم ملفات الواجهة الثابتة من `public/` وتشغيل API في Worker نفسه. D1 تحفظ البيانات، وWorkers AI يحلل السيرة، وBrowser Run يشغل Playwright للاختبار/الأتمتة. لا حاجة إلى Lovable لتشغيل التطبيق بعد بنائه، ولا حاجة إلى ChatGPT.

التوثيق:
- https://developers.cloudflare.com/workers/static-assets/
- https://developers.cloudflare.com/browser-run/playwright/
- https://developers.cloudflare.com/browser-run/limits/
- https://developers.cloudflare.com/d1/worker-api/

## تشغيل سريع لأغراض التطوير (إذا كان لديك بيئة Node أو خدمة بناء سحابية)

```bash
npm install
npx wrangler login
npx wrangler d1 create saudi-job-copilot-db
```

انسخ `database_id` الذي ينتج من الأمر إلى `wrangler.jsonc` بدل `REPLACE_WITH_D1_DATABASE_ID`، ثم:

```bash
npm run db:local
npm run dev
```

للنشر مع ربط قاعدة البيانات البعيدة:

```bash
npm run db:remote
npx wrangler secret put APP_TOKEN
npm run deploy
```

**APP_TOKEN**: أنشئ قيمة عشوائية طويلة لا تقل عن 24 حرفًا، ولا ترفعها إلى GitHub. وبدل الاعتماد على كلمة مرور شخصية سهلة اختر رمزًا عشوائيًا فريدًا. لا تضع أي بيانات حقيقية قبل اختبار التحكم بالوصول.

لتفعيل تجربة المتصفح الوهمية: غيّر `ENABLE_BROWSER_DEMO` إلى `true` في `wrangler.jsonc` وانشر مجددًا. تستهلك التجربة جزءًا من حصة Browser Run المجانية، وتبقى معطلة افتراضيًا.

**من الجوال فقط:** ملف ZIP جاهز لإضافته إلى مستودع GitHub خاص وربطه ببناء Cloudflare، لكن يلزم إنشاء D1 وضبط الأسرار والربط من لوحة Cloudflare. لا يوجد اتصال مباشر بحساب Cloudflare في هذه الجلسة؛ لذا لا تُفسر الملفات على أنها منشورة. يمكنك استخدام موقع Cloudflare من متصفح الجوال بواجهة سطح المكتب إذا تعذر عرض الإعدادات. لا تربط GitHub Deploy إلا بعد إكمال الإعدادات.

## منع الإنفاق

الخطة مصممة لاستخدام Workers Free وD1 Free وWorkers AI المجاني وBrowser Run المجاني، لكنها ليست ضمانًا بتلبية كل الاستخدامات. **لا ترقِّ إلى خطة مدفوعة ولا تضف وسيلة فوترة** حتى تراجع حدود الخدمات بنفسك. حصة Browser Run Free المؤكدة حاليًا 10 دقائق متصفح يوميًا؛ تتوقف الزيادة بدل التحول تلقائيًا إلى حصة مدفوعة في الخطة المجانية.

## استخدام سريع للواجهة

1. افتح `masar-preview.html` لمعاينة شكل الصفحة تجريبيًا دون حفظ سيرة حقيقية.
2. بعد النشر وربط قاعدة D1 أدخل `APP_TOKEN` من زر القفل.
3. أضف سيرتك الفعلية من النص، والمناصب التي تختارها بنفسك.
4. أضف إعلان وظيفة يدويًا، ثم اضغط تحليل الملاءمة أو تجهيز طلب للمراجعة.
5. من الإعدادات شغّل اختبار Cloudflare Browser Run الوهمي فقط بعد الموافقة على استهلاك دقائق مجانية.


## تحديث مصادر التوظيف — v0.2 (مرشح، غير متصل)

أضفنا ملف `src/source-groups.mjs` ولوحة «مجموعات مصادر التوظيف السعودية» في الإعدادات، مع API للقراءة فقط `GET /api/source-groups` خلف رمز الإدارة. تشمل LinkedIn وبيت.كوم وGulfTalent وNaukrigulf وتنقيب وجدارات ومواقع الشركات وأنظمة Workday/Oracle/SAP SuccessFactors/Greenhouse/Ashby/Lever/SmartRecruiters وبريد التوظيف. هذه قائمة اختبار وليست موصلات تشغيل.

**LinkedIn:** لا يوجد اتصال بحساب المستخدم ولا تقديم تلقائي. تنتظر هذه القناة طريقة مصرّحًا بها. وضع خمس دقائق بين الطلبات ليس ضمانًا للامتثال أو تجنب التقييد؛ لا تضف أساليب إخفاء أتمتة أو تجاوز تحديات المنصة. يمكن لمسار اكتشاف الوظيفة الإشارة إلى صفحة تقديم الشركة الخارجية، والتحقق من المسار بمعزل عن LinkedIn.

**قيد التنفيذ:** لا يوجد إرسال فعلي في هذا الإصدار؛ محرك Browser Run الحالي نموذج وهمي فقط. المحتوى المهني الفعلي ومواقع التوظيف المستهدفة تحدد بعد تحميل السيرة واختيار المناصب.
